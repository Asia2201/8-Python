Блок 1: Створення однорядкового текстового поля (Entry)

Теорія

Віджет Entry в графічній бібліотеці tkinter використовується для введення одного рядка тексту (наприклад, ім'я користувача, пароль чи числове значення).

Основні параметри Entry:
  • width — ширина поля у кількостях символів (наприклад, width=20).
  • bg (або background) — колір фону текстового поля.
  • fg (або foreground) — колір тексту.
  • show — символ, яким замінюється введений текст (наприклад, show="*" для приховування пароля).
Приклад коду в Python:
from tkinter import *

root = Tk()
root.geometry("300x150")

# Створення текстового поля
ent = Entry(root, width=25, bg="lightyellow", fg="blue")
ent.pack(pady=20)

root.mainloop()

Блок 2: Методи get(), insert() та delete()

Теорія

Для керування текстовим вмістом поля Entry використовують 3 ключових методи:

  1. .get() — повертає поточний рядок, введений у поле (тип даних str).
  2. .insert(index, "текст") — вставляє вказаний текст у позицію index (наприклад, 0 — на початок).
  3. .delete(first, last) — видаляє символи у діапазоні від first до last (щоб очистити все поле, використовують .delete(0, END)).

Блок 3: Багаторядковий текст (Text) та Scrollbar

Теорія

Якщо необхідно ввести або відобразити **декілька рядків тексту**, використовується віджет Text.

  • Індексація: Позиції записуються у вигляді рядка "рядок.стовпець". Наприклад, "1.0" — перший рядок, перший символ (символ 0).
  • Очищення та вставка: txt.insert("1.0", "Текст"), txt.get("1.0", END).
  • Режими переносу (wrap): WORD (по словах), CHAR (по символах), NONE (без переносу).
from tkinter import *

root = Tk()
# Створення багаторядкового поля
txt = Text(root, width=30, height=8, wrap=WORD)
txt.pack(side=LEFT, fill=BOTH)

# Додавання смуги прокручування
scroll = Scrollbar(root, command=txt.yview)
scroll.pack(side=RIGHT, fill=Y)
txt.config(yscrollcommand=scroll.set)

root.mainloop()

Блок 4: Обробка подій та клавіша <Return>

Теорія

Щоб програма реагувала на натискання клавіші Enter безпосередньо у полі Entry, використовують метод .bind().

  • Подія клавіші Enter позначається як "<Return>".
  • Функція-обробник обов'язково повинна приймати один параметр — об'єкт події (зазвичай записують event).
def on_enter(event):
    print("Введено:", ent.get())

ent = Entry(root)
# Прив'язка події Enter до поля Entry
ent.bind("", on_enter)
ent.pack()
