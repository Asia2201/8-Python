Блок 1: Створення однорядкового текстового поля (Entry)

Віджет Entry в бібліотці tkinter призначений для введення одного рядка тексту (наприклад: ім'я, логін, число).

Синтаксис створення:
from tkinter import *

root = Tk()
root.title("Моя програма")
root.geometry("300x200")

# Створення поля Entry
ent = Entry(root, width=20, fg="black", bg="white")
ent.pack(pady=10)

root.mainloop()
Візуальний підкажчик параметрів:
  • width — ширина поля в символах.
  • fg / foreground — колір тексту.
  • bg / background — колір фону.
  • show — символ для маскування (наприклад, show="*" для паролів).

Блок 2: Методи get(), insert() та delete()

Для роботи з вмістом текстового поля використовуються три основні методи:

Метод Опис Приклад використання
.get() Зчитує поточний текст із поля. Повертає рядок (str). text = ent.get()
.insert(index, str) Вставляє текст str у позицію index (наприклад, 0 або END). ent.insert(0, "Привіт!")
.delete(first, last) Видаляє символи з позиції first до last. ent.delete(0, END) # очистити все поле

Блок 3: Багаторядкове текстове поле (Text) та Scrollbar

Коли потрібно ввести або відобразити декілька рядків тексту, використовують віджет Text.

Індексація в Text:

В віджеті Text індекси записуються у форматі "рядок.стовпець" (наприклад, "1.0" — перший рядок, перший символ).

from tkinter import *

root = Tk()
txt = Text(root, width=40, height=10, wrap=WORD)
txt.pack(side=LEFT, fill=BOTH)

# Додавання прокручування (Scrollbar)
scroll = Scrollbar(root, command=txt.yview)
scroll.pack(side=RIGHT, fill=Y)
txt.config(yscrollcommand=scroll.set)

txt.insert("1.0", "Перший рядок\nДругий рядок")
root.mainloop()
Режими переносу тексту (wrap):
  • wrap=WORD — перенос по цілих словах.
  • wrap=CHAR — перенос по окремих символах.
  • wrap=NONE — без переносу (з'являється горизонтальна смуга).

Блок 4: Обробка подій та клавіша <Return>

Щоб програма реагувала на натискання клавіші Enter у полі Entry, використовують метод .bind().

def process_enter(event):
    user_text = ent.get()
    label.config(text=f"Ви ввели: {user_text}")

ent = Entry(root)
# Прив'язка події натискання клавіші Enter
ent.bind("", process_enter)
ent.pack()
