# Інтерактивна практична робота «Текстові поля в Python» (8 клас)

Повноцінний інтерактивний навчальний вебзастосунок для учнів 8 класу з теми **«Текстові поля в Python»** (робота з віджетами введення тексту `Entry` та `Text`, властивостями, подіями, валідацією, перетворенням типів і конструюванням власної форми).

## Склад проєкту
- `index.html` — головна сторінка практичної роботи та інтерфейс усіх етапів;
- `css/style.css` — додаткові стилі, адаптивність та правила друку звіту;
- `js/questions.js` — база теоретичних питань, візуальних завдань, Drag & Drop та відкритих запитань;
- `js/simulators.js` — 6 інтерактивних симуляторів роботи з текстовими полями;
- `js/logo-editor.js` — «Творча майстерня» (конструктор/симулятор власної форми чи міні-інтерфейсу з експортом у PNG та JSON);
- `js/report.js` — підрахунок балів за 12-бальною шкалою, аналітичний звіт, друк та експорт у PDF;
- `js/app.js` — навігація, реєстрація учня, збереження прогресу в `LocalStorage` та перевірка якості;
- `assets/` — директорія для графічних ресурсів;
- `.nojekyll` — файл для коректної публікації статичного сайту на GitHub Pages.

## Як розгорнути на GitHub Pages

1. **Розпакуйте архів** у зручну папку на комп'ютері.
2. **Завантажте проєкт на GitHub**: створіть новий репозиторій на GitHub (наприклад, `python-text-fields-8grade`) та завантажте туди всі файли й папки з кореня розпакованого каталогу (`index.html`, `css/`, `js/`, `assets/`, `.nojekyll`, `README.md`).
3. **Увімкніть GitHub Pages**: у репозиторії перейдіть у вкладку **Settings → Pages**, у розділі **Build and deployment** оберіть джерело **Deploy from a branch**, гілку **main** (або **master**) і папку **/(root)**, після чого натисніть **Save**.
4. **Отримайте посилання на опублікований сайт**: за кілька хвилин сайт буде доступний за адресою `https://<ваш-логін>.github.io/<назва-репозиторію>/`.
5. **Оновлюйте файли за потреби**: відредагуйте потрібні файли локально та завантажте їх у репозиторій із заміною (або через `git commit` і `git push`), після чого GitHub Pages автоматично оновить сторінку.
