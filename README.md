# PYTHON GUI LAB — ТЕКСТОВІ ПОЛЯ

Інтерактивний навчальний вебсайт з інформатики для учнів 8-го класу на тему **«Текстові поля в Python» (бібліотека Tkinter)**.

## 🚀 Особливості проєкту
- **Стиль Digital Lab**: сучасний адаптивний дизайн з використанням HTML5, CSS3, JavaScript.
- **Розділ Теорії**: 10 наочних тем із прикладами коду для `Entry()`, `get()`, `delete()`, `insert()`, `Label()`, `Button()`.
- **Інтерактивний Тренажер**: 5 практичних вправ (доповнення коду, пошук помилок, прогнозування результату).
- **Практична Майстерня**: 3 рівні завдань із вбудованою симуляцією роботи вікна Tkinter у браузері.
- **Підсумковий Тест**: 10 контрольних запитань з автоматичною перевіркою та оцінюванням.
- **Автоматичний Звіт**: Розрахунок результату, діаграма Chart.js та функція експорту в PDF / друку.

## 📁 Структура проєкту
```text
python-text-fields/
├── index.html        # Головна сторінка вебсайту
├── css/
│   └── style.css     # Стилі та оформлення (Digital Lab)
├── js/
│   └── script.js    # Логіка, тренажер, тест, звіт
├── images/           # Графічні матеріали (за наявності)
└── README.md         # Опис та інструкція з запуску
```

## 🛠️ Як запустити проєкт локально
1. Завантажте архів проєкту та розпакуйте його.
2. Відкрийте файл `index.html` у будь-якому сучасному браузері (Chrome, Firefox, Edge, Safari).
3. Серверний запуск **не потрібен** — усе працює автономно.

## 🌐 Публікація на GitHub Pages
1. Створіть новий публічний репозиторій на [GitHub](https://github.com).
2. Завантажте вміст папки `python-text-fields/` у ваш репозиторій.
3. Перейдіть у **Settings** (Налаштування репозиторію) -> **Pages**.
4. У розділі **Build and deployment** під **Source** виберіть гілку `main` (або `master`) та папку `/ (root)`.
5. Натисніть **Save**. Через 1-2 хвилини ваш сайт стане доступним за посиланням: `https://<ваш-username>.github.io/<назва-репозиторію>/`.
