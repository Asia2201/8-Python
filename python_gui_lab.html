1. Що таке графічний інтерфейс користувача (GUI)?

GUI (Graphical User Interface) — це спосіб взаємодії користувача з програмою за допомогою вікон, кнопок, текстових полів та іконок замість введення текстових команд у чорну консоль.

Python code (Tkinter) 
from tkinter import *
root = Tk()
root.title("Моя програма")
root.geometry("300x200")
root.mainloop()

Пояснення команд:

Tk() створює головне вікно програми. mainloop() запускає нескінченний цикл обробки подій вікна.
